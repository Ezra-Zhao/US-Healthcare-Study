# US-Healthcare-Study｜美国就医与医疗学习笔记

在美国看病这件事，对新移民来说是一套完全陌生的系统：执照怎么考、急诊怎么分诊、处方怎么拿、眼镜怎么配、自己的病历有哪些权利。这个仓库把学习过程按主题记下来：执照备考路线、教学病例拆解、日常就医流程、医疗相关法律法规。

每篇文章都是三语对照：中文为主，英文次之，西班牙语为学习译稿。同一文件内按小节排三个版本，方便对照着读。

作者：Guangyi Zhao
